
# E-Commerce Sales & Customer Analytics
## Project Overview
This project analyzes e-commerce sales and customer data to identify sales trends, customer behavior, product performance, regional performance, and payment preferences.
The project follows a complete data analytics workflow:
Kaggle Dataset → Python/Pandas Data Cleaning → Data Analysis → Power BI Dashboard → Business Insights
##  Objectives
- Analyze overall sales and revenue performance
- Identify high-performing product categories
- Analyze monthly sales trends
- Compare regional sales performance
- Understand payment method preferences
- Identify high-value and repeat customers
- Generate meaningful business insights
## Dataset
The project uses an e-commerce sales dataset containing information about orders, customers, products, regions, payment methods, delivery, ratings, and revenue.
The dataset contains 5,000 records and 12 original attributes.
Key attributes include:
- Order ID
- Order Date
- Customer ID
- Product Category
- Region
- Quantity
- Unit Price
- Discount
- Payment Method
- Delivery Days
- Customer Rating
- Revenue

  ## Data Cleaning
The dataset was cleaned and prepared using Python and Pandas in Jupyter Notebook.
The main data preparation steps included:
- Checked the dataset structure and data types
- Checked for missing values
- Checked and removed duplicate records
- Converted the order date into a proper datetime format
- Validated categorical values
- Checked numerical value ranges for consistency
- Created Year, Month, and Month Name columns
- Validated revenue calculations against quantity, unit price, and discount
## Data Analysis
The cleaned dataset was analyzed to understand different aspects of e-commerce performance:
- Overall revenue and average revenue per order
- Revenue and order volume by product category
- Monthly revenue trends and growth
- Regional revenue and order performance
- Payment method usage and revenue
- Top customers based on revenue and order count
- Repeat customer analysis
- Customer rating analysis

## Key Results
- Total revenue generated was approximately ₹5.11 million.
- Electronics generated the highest total revenue among all product categories.
- Electronics also recorded the highest number of orders.
- Beauty had the highest average revenue per order.
- Monthly revenue showed an overall declining trend during the analyzed period.
- Regional, payment method, and customer-level analysis were performed to identify business patterns.
